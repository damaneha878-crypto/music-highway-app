# Music Highway

A cinematic music artist website built with React and Vite.

## Getting started

1. Install dependencies
   ```bash
   npm install
   ```
2. Run the app locally
   ```bash
   npm run dev
   ```
3. Build for production
   ```bash
   npm run build
   ```

## Features

- Full-screen musician landing page
- Responsive dark aesthetic
- Featured release cards
- Tour date section
- Gallery and fan signup UI
- Interactive music player
